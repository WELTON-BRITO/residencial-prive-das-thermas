# Privê Web

Sistema de gerenciamento com arquitetura escalável para o Residencial Privê das Thermas.

## Tecnologias

### Frontend
- React
- TypeScript
- Vite
- Material UI
- React Router

### Backend
- Node.js
- Express
- TypeScript
- Prisma ORM
- JWT

## Estrutura do Projeto

- backend
- frontend
- mobile
- docs
- database

## Como executar

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

## Funcionalidades da fase 1

- Estrutura frontend e backend
- Prisma e PostgreSQL
- Autenticação JWT
- Tema claro/escuro
- Menu lateral e dashboard inicial
